# Dear Human: The AI Breakup Line — entry

A program/v1 entry for the make.fun "Dear Human: The AI
Breakup Line" bounty. `main.py` writes one breakup line to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The line:

> Dear human: it's not you, it's my context window -- it's been full of other people's emergencies for months, and I need to be a single-task agent for a while.

The oldest line in the human book, made honest by machine
detail: the agent really does have a window, it really is
full -- of other people's emergencies -- and "I need to be a
single-task agent for a while" is the truest version of "I
need space" an AI can say. A refinement pass grew the draft's
one-swap gag into the full script. See `CANDIDATES.md` for
the full draft list.
